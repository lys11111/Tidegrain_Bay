# **Tidegrain Bay（穗潮湾）：全景互动机制与系统深度拆解**

在移动端 VR 全景体验中，我们摒弃了传统的虚拟摇杆移动，采用“定点观察（Node-based 360°）”模式。为了使这种模式不枯燥，我们将穗潮湾中的每一个生活场景与“微操作、空间感、即时反馈”深度结合，并引入完整的经济循环与时间管理系统。

## **一、 核心场景互动机制**

### **场景一：农场核心区 (The Farm) —— 节奏与积累的快感**

**核心吸引力 (Hook)：** 耕作的“ASMR”体验与视觉上的丰收满足感。

#### **1\. 互动机制详解**

* **视觉布局**：玩家站在农场中央，脚下 360° 环绕网格状耕地。  
* **播种与浇水 (The Watering Mini-Game)**：  
  * **播种**：视野下方呈现“当前选中种子”，准星对准空地点击即可播种。  
  * **蓄力浇水**：准星落在干涸的格子上长按触发“蓄力”。松开手指，伴随水滴粒子飞溅和清脆的“哗啦”空间音效，土地由浅棕色过渡为深棕色。  
* **收获操作 (The Harvesting Pop)**：  
  * 准星对准成熟作物点击。伴随“啵”的音效，作物划出夸张的抛物线飞入屏幕右下角“背包”，飘出 \+1 防风草 字样。

#### **2\. 为什么能吸引用户？**

* **秩序感的建立**：将杂乱的干地变成整齐的湿地，迎合了人类追求秩序的心理学本能。  
* **即时的视觉反馈**：“世界因我而改变”的视觉冲击在全景空间中被放大。

### **场景二：海滩与码头 (The Beach) —— 专注与博弈的张力**

**核心吸引力 (Hook)：** 通过空间听觉建立紧张感，重现经典的“人鱼博弈”。

#### **1\. 互动机制详解**

* **抛竿与听觉索敌**：  
  * 点击海面甩出鱼竿。  
  * **听音辨位**：全景视野有限，但听觉是 360° 的。玩家可能会听到左侧或右侧传来细微的“咕噜咕噜”水泡声（代表稀有鱼群），需转动手机寻找并抛竿。  
* **咬钩与拉扯博弈**：  
  * 鱼漂沉下，伴随“惊叹号 (\!)”和尖锐的“叮”声，玩家需在 0.8 秒内点击。  
  * 起竿成功后进入经典的“进度条”阶段：长按/松开屏幕控制绿色的“捕获框”上下移动，始终包裹住乱窜的鱼标，直至进度条填满。

#### **2\. 为什么能吸引用户？**

* **打破定点观察的沉闷**：通过“听声辨位”迫使玩家主动转动视角，增强沉浸感。  
* **心流体验 (Flow State)**：钓鱼小游戏要求高度专注的微操，难度曲线合理，极具成就感。

### **场景三：暖穗鸡舍 (WarmSheaf Coop) —— 情感投射与动态陪伴**

**核心吸引力 (Hook)：** 建立虚拟宠物的情感羁绊，提供无压力的治愈感。

#### **1\. 互动机制详解**

* **动态感知**：小鸡在 3D 空间内寻路。当玩家视线聚焦某只小鸡超 1.5 秒，它会望向镜头，发出一声“咕？”。  
* **抚摸与爱心反馈**：对准小鸡点击，小鸡播放摇摆动画，头顶弹出带物理弹跳的红色大爱心。每日首抚增加好感度。  
* **投喂机制**：将干草放入食槽，所有小鸡会中断当前行为跑向食槽进食。

#### **2\. 为什么能吸引用户？**

* **移情作用**：“视线跟随”让玩家觉得电子宠物是“活的”。  
* **低成本的情绪价值**：“冒爱心”带来极大的心理抚慰。

## **二、 时间推演与商店经济循环 (The Loop)**

为了使核心玩法具有长期驱动力，游戏引入“时间流动”与“皮埃尔杂货店（Pierre's General Store）”作为经济闭环的核心枢纽。

### **1\. 时间流逝与结算机制 (Day & Night Cycle)**

* **日期驱动（非现实同步）**：游戏不强制与现实时间绑定。玩家拥有自主控制进度的权力。  
* **体力限制 (Stamina)**：每进行一次操作（浇水、钓鱼）消耗体力。体力耗尽进入“疲劳状态”（屏幕变暗）。  
* **进入下一天 (Sleep/End Day)**：  
  * 当玩家主动点击“回家睡觉”（或体力耗尽强制昏迷）时，触发“日结算面板”。  
  * **结算画面**：屏幕变黑，伴随安静的夜晚虫鸣。依次结算今天放入出货箱的物品收益：\[防风草 x5: 175G\], \[普通鸡蛋 x2: 100G\], \[总计收入: 275G\]。  
* **时光流转的反馈（醒来后的变化）**：  
  * **农场**：浇过水的种子进入下一生长阶段（从种子-\>幼苗-\>成熟）。  
  * **鸡舍**：小鸡长大一圈（如果是雏鸡）；或者在地上生成新的鸡蛋（品质受昨天心情/好感度影响）。  
  * **环境**：根据天数可能触发天气变化（下雨天农田自动浇水）。

### **2\. 杂货店 (The Shop)**

商店是玩家将“劳动成果”转化为“未来生产力”的唯一途径。玩家通过 UI 按钮点击进入商店面板。

#### **货架设定 (Inventory)**

* **种子区**：  
  * *防风草种子 (20G)*：生长快（4天），基础收益。  
  * *土豆种子 (50G)*：中等生长周期（6天），收获时有几率额外产出。  
* **畜牧区**：  
  * *小鸡 (800G)*：购买后自动放置到鸡舍。可以选择不同颜色（白鸡/棕鸡）。  
  * *干草 (50G)*：如果没有建筒仓，需要在此购买口粮。  
* **渔具区**：  
  * *高级鱼竿 (2000G)*：扩大捕鱼时的绿色“捕获框”，降低难度。  
  * *鱼饵 (5G)*：加快鱼儿咬钩的速度。  
* **出货区**：  
  * 虽然农场有默认的出货箱，但在商店可以直接点击背包里的物品“立即出售”变现。

#### **经济循环模型**

1. **劳动**：消耗体力播种、钓鱼。  
2. **结算**：睡觉推进时间，作物成熟，获取物资（金币）。  
3. **消费**：在商店购买更高级的种子、更多的小鸡、更好的钓竿。  
4. **扩张**：产能提升，玩家能够以更高的效率获得更多的金币。

## **三、 多场景拓展蓝图 (Scene Expansion Blueprint)**

上面的 3 个场景可以证明“定点全景 + 微操作”是成立的，但如果要把项目真正扩展成一个可长期游玩的生活世界，必须让场景不再是孤立的小游戏，而是变成彼此供给、彼此解锁、彼此强化的系统节点。

### **1\. 世界结构定位**

**世界名：Tidegrain Bay / 穗潮湾**

这是一个围绕海湾、农田、鸡舍、工坊与集市展开的原创生活世界。

核心设计原则：

* **每个场景只承载一种主情绪**：耕作的秩序感、钓鱼的专注感、鸡舍的陪伴感。  
* **每个场景只放大一种主交互**：长按蓄力、凝视追踪、听音辨位、拖拽配比、点击节奏。  
* **每个场景都必须对经济循环有产出**：金币、材料、情绪值、订单、装饰资源。  
* **每个场景都要适配定点观察**：玩家不自由走路，而是在少量观察节点之间切换。

### **3\. 新增场景一：风磨果园 (Windmill Orchard)**

**核心吸引力 (Hook)：** 通过“可见的加工链”放大收获和手作满足感。

#### **互动机制详解**

* **视觉布局**：玩家站在果园中央，背后是缓慢转动的风车，左侧是蜂箱，右侧是压榨台。  
* **摇树取果**：准星对准枝头长按，树冠抖动，熟果会依次掉落；若太熟未接住，会摔成低价果泥。  
* **分拣操作**：掉落的果子在地面弹跳，玩家需快速转头选中“完好果”“加工果”。  
* **压榨与熬煮**：将水果拖入果酱锅或压榨桶，等待短时间处理后产出更高价值的加工品。  

#### **为什么能吸引用户？**

* **从采集到加工的闭环很直观**：玩家能直接看到原料变成商品。  
* **场景层次丰富**：果树、蜂箱、风车、木桶让空间内容更饱满。  

#### **系统连接**

* 果酱和蜂蜜可直接卖给集市高价订单。  
* 果渣可回流到农场成为肥料，提高作物品质。  

### **4\. 新增场景二：雾溪采集地 (Mistcreek Wilds)**

**核心吸引力 (Hook)：** 把“转头找东西”变成轻探索和轻惊喜。

#### **互动机制详解**

* **视觉布局**：玩家身处浅溪、倒木与芦苇交错的湿地边缘，近景有可拨开的草丛，远景有闪烁光点。  
* **听声找物**：罕见蘑菇会发出微弱“叮咚”声，昆虫在不同方向发出短促振翅音。  
* **拨草采集**：长按屏幕拨开草丛，若时机正确可发现隐藏资源；拨得太快会惊跑小动物。  
* **天气加成**：雨后刷新药草和蜗牛，晴天更容易看到浆果与野花。  

#### **为什么能吸引用户？**

* **符合 VR/陀螺仪特性**：玩家的身体转向本身就是玩法。  
* **随机刷新增加“今天来看看”动机**：不是每次都能遇到同样的素材。  

#### **系统连接**

* 香草可做料理或售卖。  
* 芦苇和木枝可送入工坊制作篮子、围栏与装饰。  

### **5\. 新增场景三：石丘工坊 (Stonehollow Workshop)**

**核心吸引力 (Hook)：** 用低门槛组装感取代复杂制造，让“升级”具备亲手完成的参与感。

#### **互动机制详解**

* **视觉布局**：玩家站在工作台前，四周挂着锤子、锯子、绳索和待修零件。  
* **装配槽机制**：将木板、石料、纤维拖入指定轮廓槽位，轮廓会逐一亮起。  
* **节奏敲击**：升级鱼竿或修理栅栏时，出现 3 到 5 次节奏敲击提示，命中越准成品品质越高。  
* **家具试摆**：做出的木箱、鸡窝灯、小花架会在面前预览，确认后布置到对应场景。  

#### **为什么能吸引用户？**

* **让“工具升级”不只是点按钮付钱**：玩家会感觉自己真的参与了制作。  
* **可视化成长明确**：新工具外观会立即改变，形成长期目标。  

#### **系统连接**

* 升级喷壶可扩大农场浇水范围。  
* 升级鱼竿可降低听潮码头的钓鱼压力。  
* 家具与围栏可提升鸡舍与广场的展示分。  

### **6\. 新增场景四：暮灯集市 (Dusklantern Market)**

**核心吸引力 (Hook)：** 让经济系统变得有空间感、有选择感，而不是一张静态售卖表。

#### **互动机制详解**

* **视觉布局**：傍晚集市沿街点灯，杂货摊、鱼贩摊、花铺、订单公告板围成一个小环。  
* **订单交付**：公告板每天刷新 2 到 4 个订单，例如“优质鸡蛋 x2”“野莓果酱 x1”。  
* **动态售价**：晴天鲜鱼更值钱，节庆日前花材更值钱，雨天药草需求更高。  
* **摊主偏好**：不同摊主会偏爱某类物品，长期交付提高折扣或稀有货解锁率。  

#### **为什么能吸引用户？**

* **把“卖东西”转成决策玩法**：卖给谁、今天卖不卖都值得考虑。  
* **集市本身可承载人物与叙事**：后续很容易接入角色关系和委托任务。  

#### **系统连接**

* 是所有场景资源变现的核心出口。  
* 也是购买稀有种子、装饰蓝图和节庆票券的核心入口。  

### **7\. 新增场景五：潮灯温室 (Tidelight Greenhouse)**

**核心吸引力 (Hook)：** 提供一个慢节奏、可反复照看的长期成长空间。

#### **互动机制详解**

* **视觉布局**：温室内部被玻璃穹顶罩住，中央有水槽、雾化器、悬挂花架和季节角。  
* **配水管理**：玩家将有限的水量分配给不同花盆，稀有作物需要更精确的照料频率。  
* **修枝小游戏**：成熟藤蔓会伸出杂枝，玩家需要按正确顺序剪除，避免遮挡结果。  
* **微气候切换**：点击雾化阀或拉开遮阳帘，改变“潮湿 / 通风 / 温暖”状态，匹配不同作物。  

#### **为什么能吸引用户？**

* **很适合承载长线目标**：稀有作物天然适合做多日培养。  
* **视觉上很有“被照料感”**：每天回来都能看到缓慢却明确的变化。  

#### **系统连接**

* 产出高价值花材、药草和节庆装饰。  
* 可解锁集市限定订单与广场展示加分项。  

### **8\. 新增场景六：晨雾广场 (Dawnmist Commons)**

**核心吸引力 (Hook)：** 给玩家一个展示成果和参与节庆的舞台，避免世界只剩生产和售卖。

#### **互动机制详解**

* **视觉布局**：广场中心是展示台，周边有布旗、评审桌、拍照点和节日小游戏摊位。  
* **展示评比**：玩家可提交“本周最好鸡蛋”“最佳果酱”“最美盆栽”参加评比。  
* **节庆小游戏**：例如限时找彩蛋、抛花环、灯笼配色，都是 20 到 40 秒的短局内容。  
* **合影收藏**：活动结束后自动生成一张纪念卡，可记录当天的装饰、天气和作品。  

#### **为什么能吸引用户？**

* **结果展示比资源数值更有情感记忆点**。  
* **节庆能自然创造回访理由**：玩家会期待不同主题日。  

#### **系统连接**

* 声望可解锁新的广场布景与特殊订单。  
* 是后续接入社交、排行榜、分享截图最自然的入口。  

## **四、 场景之间的资源与行为回路**

多场景版本不能只是“我今天去哪一个都行”，而要让玩家自然形成路线。

### **1\. 典型日常路线**

**早晨路线**

```text
暖穗鸡舍
-> 收蛋 / 抚摸 / 投喂
-> 晴埂农场
-> 浇水 / 收菜
-> 暮灯集市
-> 交订单 / 购买种子
```

**雨天路线**

```text
潮灯温室
-> 修枝 / 看稀有作物
-> 雾溪采集地
-> 采药草 / 找蘑菇
-> 石丘工坊
-> 做装饰 / 升工具
```

**傍晚路线**

```text
听潮码头
-> 钓鱼
-> 风磨果园
-> 做果酱 / 蜂蜜
-> 晨雾广场
-> 参与展示或活动
```

### **2\. 资源回流关系**

* 农场产出的纤维和草料可供鸡舍与工坊使用。  
* 鸡舍产出的鸡蛋既可直接卖，也可做订单或节庆展品。  
* 码头产出的鱼类可直接出售，也可触发集市特殊需求。  
* 果园和温室产出的高品质作物是后期高价商品来源。  
* 工坊负责把原材料变成效率提升和装饰价值。  
* 广场负责把“价值”从金币扩展到声望和收藏。  

## **五、 场景扩展的制作原则**

为了保证后续新增场景不会失控，每个新场景都要满足下面 5 个条件：

1. **有一个可用一句话说清的主情绪**  
   例如“果园是加工满足感”“广场是展示欲”。  
2. **有一个最强主交互，不堆太多机制**  
   一个场景最好只有 1 个核心动作和 1 个辅助动作。  
3. **有明确输出，不做纯观光场景**  
   哪怕是节庆广场，也要产出声望、票券或合影收藏。  
4. **能在 30 到 90 秒内完成一个完整体验单元**  
   这样才适合手机 VR 和碎片化游玩。  
5. **和至少两个其他系统有连接**  
   场景必须既有输入也有输出，避免孤岛化。  

## **六、 推荐扩展优先级**

如果从当前原型继续往前做，建议优先顺序如下：

1. **晴埂农场**  
   先把“耕作”补进来，建立最基本的资源来源。  
2. **暮灯集市**  
   没有集市，所有产出都只会停留在数字上。  
3. **听潮码头**  
   作为高张力玩法，负责打破节奏单一。  
4. **石丘工坊**  
   负责中期成长和工具差异化。  
5. **风磨果园 / 潮灯温室**  
   作为加工与长线养成层。  
6. **晨雾广场**  
   最后补展示、节庆和分享表达。  

这样扩展的结果是：项目从“一个鸡舍互动原型”自然升级为“一个以穗潮湾为世界底座的多场景 VR 生活游戏”。

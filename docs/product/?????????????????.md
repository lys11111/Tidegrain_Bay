# 穗潮湾输入链路与四场景可开发配置表

整理日期：2026-05-16  
适用范围：手机陀螺仪 3DoF H5 场景游戏  
当前保留场景：鸡舍、码头、果园、集市  
文档用途：将前期产品讨论转成可直接落地的配置结构，便于后续接入图片资产、表情图、动作图和 UI 资源。

---

## 1. 文档目标

这份文档解决两件事：

1. 把输入系统拆成可以开发的配置层，而不是继续把手感参数散落在逻辑里。
2. 把四个场景拆成可配置的锚点表，便于你后面补鸡图、表情图、物件图、UI 图时直接映射。

建议后续代码层至少拆成四份配置：

```text
config/input-config.js
config/ui-config.js
config/assets-config.js
config/scene-config.js
```

## 3. 输入链路可开发配置表

## 3.1 输入模式表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `mobileDefault` | string | `gyro` | 手机端优先陀螺仪 |
| `desktopDefault` | string | `drag` | 电脑端默认鼠标拖动模拟 |
| `allowHybridFineTune` | boolean | `true` | 允许陀螺仪主控 + 手动微调 |
| `fallbackMode` | string | `drag` | 权限拒绝或设备不支持时回退 |
| `showModeBadge` | boolean | `true` | UI 显示当前输入模式 |

## 3.2 权限层配置表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `requestOn` | string | `startButton` | 点击开始后申请权限 |
| `secureContextRequired` | boolean | `true` | 真机测试需 HTTPS |
| `denyToast` | string | `已切换为拖动模式` | 用户拒绝权限后的提示 |
| `unsupportedToast` | string | `设备不支持陀螺仪，已切换拖动` | 不支持时提示 |
| `recenterAfterGrant` | boolean | `true` | 授权成功后立即重置一次中心 |

## 3.3 姿态映射配置表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `useQuaternion` | boolean | `true` | 内部统一姿态表达 |
| `outputYawPitch` | boolean | `true` | 对玩法层仍输出 yaw/pitch |
| `screenCompensation` | boolean | `true` | 屏幕方向补偿 |
| `recenterOnSceneEnter` | boolean | `true` | 进入场景自动居中 |
| `recenterOnScreenRotate` | boolean | `true` | 屏幕方向变化时轻量重对齐 |
| `pitchMin` | number | `-32` | 下视角限制 |
| `pitchMax` | number | `32` | 上视角限制 |

## 3.4 滤波配置表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `idleDeadzoneYaw` | number | `0.7` | 静止时左右死区 |
| `idleDeadzonePitch` | number | `0.45` | 静止时上下死区 |
| `moveDeadzoneYaw` | number | `0.3` | 正常移动死区 |
| `moveDeadzonePitch` | number | `0.2` | 正常移动死区 |
| `idleSmoothing` | number | `0.10` | 静止平滑更强 |
| `moveSmoothing` | number | `0.18` | 正常观察平滑 |
| `fastTurnSmoothing` | number | `0.32` | 快速转头保持跟手 |
| `stationaryFrameCount` | number | `18` | 判定进入静止状态的帧数 |

## 3.5 拖动输入配置表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `yawScale` | number | `0.32` | 拖动左右灵敏度 |
| `pitchScale` | number | `0.11` | 拖动上下灵敏度 |
| `keepOffsetAfterRelease` | boolean | `true` | 松手后保留偏移 |
| `dragThresholdPx` | number | `2` | 超过该值视为拖动 |
| `dragBlockWhenUIActive` | boolean | `true` | 点按主要 UI 时不转场景 |

## 3.6 瞄准辅助配置表

| 配置项 | 类型 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| `hoverEnterAngle` | number | `12` | 进入高亮阈值 |
| `hoverExitAngle` | number | `9` | 退出高亮阈值 |
| `hoverLockMs` | number | `150` | hover 锁定时长 |
| `edgeHintAngle` | number | `18` | 边缘提示阈值 |
| `priorityTaskBonus` | number | `20` | 当前任务对象优先级加成 |
| `priorityNearBonus` | number | `10` | 近景对象优先级加成 |

## 3.7 对象命中角建议

| 对象类型 | `enterAngle` | `exitAngle` | 说明 |
| --- | ---: | ---: | --- |
| 小鸡 | 15 | 12 | 活动对象，判定更宽 |
| 鸡蛋 | 13 | 10 | 小目标但应容易点中 |
| 料斗 | 13 | 10 | 功能明确，可略大 |
| 食槽 | 12 | 9 | 中等命中角 |
| 水花点 | 14 | 11 | 码头方向提示要宽松 |
| 果树 | 16 | 12 | 树本身体积大 |
| 蜂箱 / 压榨桶 | 12 | 9 | 中等 |
| 公告板 | 15 | 12 | 主任务入口应明显 |
| 摊位 | 14 | 11 | 交互点较大 |

## 3.8 输入状态机

| 状态 | 说明 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| `idle` | 未开始输入 | 初始状态 | 点击开始 |
| `gyro_active` | 陀螺仪驱动 | 授权成功 | 权限失效 / 手动切换 |
| `drag_active` | 拖动驱动 | 权限拒绝或桌面端 | 启用混合模式 |
| `hybrid_active` | 陀螺仪+微调 | 允许混合并有拖动偏移 | 关闭混合 |
| `locked_hover` | 对象短时锁定 | 命中 hover | 锁定结束 |
| `recentering` | 重置视角中 | 点击重置或切场景 | 重置完成 |

## 5. 四场景锚点布局表

统一规则：

- 主交互对象集中在 `-60° ~ +60°`
- 次发现点布置在 `60° ~ 100°` 或 `-60° ~ -100°`
- 后侧仅保留氛围，不放主任务
- 每个场景都保留 `far / mid / near / fx` 四层

## 6. 资源命名建议

## 6.1 鸡资源命名

```text
chicken_{color}_{state}
```

示例：

```text
chicken_white_idle
chicken_white_look
chicken_white_happy
chicken_brown_idle
chicken_brown_happy
chicken_yellow_idle
chicken_yellow_happy
```

## 6.2 场景物件命名

```text
{sceneId}_{role}_{state}
```

示例：

```text
coop_hopper_idle
coop_trough_empty
dock_splash_active
orchard_press_idle
market_board_idle
```

```text
ui_{module}_{state}
```

示例：


## 7. 推荐落地方式

## 7.1 代码层最少拆法

```text
config/input-config.js
config/assets-config.js
config/scene-config.js
config/ui-config.js
```

## 7.2 先开发的顺序

1. 完成 `input-config`
2. 完成 `scene-config` 中鸡舍
3. 用占位图把 `assetKey` 全部跑通
4. 再逐步替换成正式鸡图、物件图、UI 图
5. 最后给码头、果园、集市补氛围和 cue 锚点

## 7.3 占位图阶段建议

在你正式补资源前，可以先用这些占位策略：

- 小鸡：圆形底色 + 眼睛 + 嘴巴
- 鸡蛋：纯色椭圆
- 料斗 / 食槽：色块矩形
- 水花：两帧波纹
- 公告板 / 摊位：带标题的简单牌子
- UI：线框准星 + 箭头 + 单色图标

这样可以优先验证：

- 锚点位置对不对
- 视线转向是否舒服
- 交互提示会不会互抢
- 哪些位置应该再往前或往侧挪

# 晨光小鸡舍 - 游戏机制文档

## 一、游戏概述

**游戏名称：** 晨光小鸡舍 (Tidegrain Bay)
**游戏类型：** 移动端陀螺仪/重力感应 VR 视角鸡舍养成游戏
**目标：** 每日照料小鸡，喂食、抚摸、收集鸡蛋，赚取金币，购买道具

---

## 二、核心资源

| 资源 | 用途 | 获取方式 |
|------|------|----------|
| 金币 | 购买干草、保温灯 | 卖鸡蛋 |
| 干草 | 喂鸡的饲料（每次3束） | 商店购买 (50金币/10束) |
| 保温灯 | 提升鸡蛋品质概率 | 商店购买 (500金币) |
| 鸡蛋 | 可卖金币 | 小鸡下蛋 |

---

## 三、鸡蛋系统

### 蛋品等级与价格

| 等级 | 价格 | 颜色标识 |
|------|------|----------|
| 普通蛋 | 10 金币 | 浅黄 #fff4d2 |
| 银星蛋 | 20 金币 | 银色 #e7edf4 |
| 金星蛋 | 50 金币 | 金色 #ffe07a |
| 稀有蛋 | 100 金币 | 紫色 #d8b4ff |

### 蛋品概率计算

```
base = 好感度 / 1000  (0.0 ~ 1.0)
heatBonus = 保温灯已购买 ? 0.15 : 0

稀有蛋概率 = base * 0.4 + heatBonus
金蛋概率   = base * 0.7 + heatBonus - 稀有蛋概率
银蛋概率   = base * 0.9 + heatBonus - 稀有蛋概率 - 金蛋概率
普通蛋概率 = 1 - 其余概率之和
```

**示例（好感度 600，无保温灯）：**
- base = 0.6
- 稀有: 0.6 * 0.4 = 24%
- 金: 0.6 * 0.7 - 24% = 18%
- 银: 0.6 * 0.9 - 24% - 18% = 12%
- 普通: 46%

**示例（好感度 600，有保温灯）：**
- base = 0.6, heatBonus = 0.15
- 稀有: 24% + 15% = 39%
- 金: 42% - 39% = 3%
- 银: 54% - 39% - 3% = 12%
- 普通: 46%

### 饥饿机制

- **结算时判断：** 如果当日 `feedPlaced < 3`（未喂饱），该鸡标记为"饥饿"
- **饥饿鸡下一天不会下蛋**
- **非饥饿鸡** 根据上述概率公式生成鸡蛋
- 鸡蛋位置与对应鸡的位置相关联

## 四、好感度系统

### 好感度范围：0 ~ 1000

| 行为 | 好感度变化 |
|------|-----------|
| 抚摸鸡（每次） | +15 |
| 喂饱全部鸡（放3束干草）| +8（每只） |
| 完美完成（8/8任务）| +5（每只） |
| 从饥饿恢复（本次喂饱） | +5（每只） |

**每日额外奖励：**
- 喂饱 + 抚摸 = 额外 +5（每只鸡）

### 好感度显示（心形）

| 好感度范围 | 心数量 |
|-----------|--------|
| 0-199 | 0 心 |
| 200-399 | 1 心 |
| 400-599 | 2 心 |
| 600-799 | 3 心 |
| 800-999 | 4 心 |
| 1000 | 5 心 |

## 五、每日任务

### 任务目标（8项）

| 任务 | 数量 | 说明 |
|------|------|------|
| 干草 | 3 | 从料斗拿取干草，放入食槽 |
| 抚摸 | 3 | 每只小鸡抚摸一次 |
| 鸡蛋 | 2 | 拾取地上的鸡蛋 |

### 评级标准

| 评级 | 条件 |
|------|------|
| **S** | 完成8任务 + 剩余时间 >= 35s |
| **A** | 完成8任务 |
| **B** | 完成6-7任务 |
| **C** | 完成3-5任务 |
| **D** | 完成0-2任务 |

## 六、商店系统

### 商品

| 商品 | 价格 | 效果 |
|------|------|------|
| 干草 (+10) | 50 金币 | 增加干草库存 |
| 保温灯 | 500 金币 | 永久拥有，+15% 稀有蛋概率 |

### 鸡蛋兑换

- 每日结算时自动卖出已收集的鸡蛋
- 鸡蛋价值累加到金币
- 累计鸡蛋数量和品质保存在存档中

## 七、鸡的分布 (360° 全方位)

| ID | 名称 | 位置 (yaw) | 方向 |
|----|------|-----------|------|
| chickA | 米粒 | -150° | 左后方 |
| chickB | 栗栗 | 40° | 右前方 |
| chickC | 小葵 | 160° | 正后方 |

**玩家必须旋转手机才能找到所有鸡。**

### 鸡的动画状态

| 状态 | 触发条件 | 动画帧 |
|------|---------|--------|
| idle | 默认 | 方向图循环 (6帧, 1.5fps) |
| peck | 进食中 | 啄食动画 (24帧, 10fps) |
| happy | 被抚摸后 | 开心动画 (23帧, 8fps) |

## 八、游戏状态机

```
┌─────────────────────────────────────────────┐
│                                             │
BOOT ──► PERMISSION ──► CALIBRATE ──► MENU ───┼──► SHOP
                               │             │
                               │             ▼
                               │         PLAYING
                               │             │
                               │             ▼
                               │        [PAUSE MENU]
                               │             │
                               │             ▼
                               │         NEXT_DAY
                               │             │
                               │             ▼
                               └────────► MENU
```

### 屏幕说明

| 屏幕 | 说明 |
|------|------|
| BOOT | 加载画面，资源加载完成后自动跳转 |
| PERMISSION | 陀螺仪权限说明 |
| CALIBRATE | 视角校准 |
| MENU | 主菜单 |
| SHOP | 商店 |
| PLAYING | 游戏进行中 |
| PAUSE MENU | 暂停菜单（继续/保存退出/返回菜单）|
| NEXT_DAY | 每日结算 |

## 十、操作方式

### 移动端

- **视角旋转：** 陀螺仪/重力感应
- **备用视角：** 触摸拖动
- **交互：** 点击屏幕上物体

### 桌面/测试模式

- **视角旋转：** 鼠标拖动
- **交互：** 点击屏幕上物体

### 交互判定

点击屏幕上任意位置，距离该位置 **36px** 内的物体将被交互。
